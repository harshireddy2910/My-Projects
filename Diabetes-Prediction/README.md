Diabetes Prediction using Machine Learning
This project predicts whether a person is likely to have diabetes using machine learning.
.Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Support Vector Machine
.Workflow
- Loaded and explored the diabetes dataset
- Preprocessed the data using standard scaling
- Split the data into training and testing sets
- Trained an SVM classification model
- Evaluated model performance using accuracy score
.Project File
- `Diabetes_prediction.ipynb`
.Dataset
The notebook uses `diabetes.csv`.
